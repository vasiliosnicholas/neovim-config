# 💤 LazyVim

A config for neovim based on the starter template for [LazyVim](https://github.com/LazyVim/LazyVim).
Refer to the [documentation](https://lazyvim.github.io/installation) to get started.

## My setup

Added some custom plugins (Eagle.nvim, ipynb.nvim) along with most lazy extras for common languages (C/C++, Java, Python, JavaScript, TypeScript). Default theme is nord (delete `./lua/plugins/colorscheme.lua` to revert to default theme)

## Installation

1. Review and install [LazyVim Requirements](https://www.lazyvim.org/#%EF%B8%8F-requirements), including optional requirements.
2. copy contents of root directory to `~/config/nvim` or where ever your neovim config is located.
